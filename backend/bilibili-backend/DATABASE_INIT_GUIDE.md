# 数据库初始化指南

## 概述

本项目提供了完整的数据库初始化方案，包含所有必要的默认数据，让您快速启动应用。

## 🚀 快速开始

### 1. 确保数据库连接正常

首先确保您的MySQL数据库已安装并运行，数据库连接配置正确。

检查 `.env` 文件中的数据库配置：
```env
DB_HOST=localhost
DB_PORT=3306
DB_USERNAME=root
DB_PASSWORD=你的密码
DB_DATABASE=bilibili
```

### 2. 运行完整数据库初始化

```bash
# 在 backend/bilibili-backend 目录下运行
npm run init-db
```

这个命令会自动创建：
- ✅ 默认管理员账户
- ✅ 系统分类数据
- ✅ 轮播图数据
- ✅ 示例内容数据

## 🔧 自定义初始化

### 修改默认数据

您可以编辑 `src/scripts/init-database.ts` 文件来自定义初始化数据：

1. **修改分类**: 编辑 `categories` 数组
2. **修改轮播图**: 编辑 `banners` 数组
3. **修改示例内容**: 编辑 `images` 数组
4. **修改管理员信息**: 修改 `createUser` 调用参数

### 添加新的初始化脚本

1. 在 `src/scripts/` 目录下创建新的 TypeScript 文件
2. 在 `package.json` 的 `scripts` 部分添加对应命令
3. 使用 `npm run your-script-name` 运行

## 🚨 注意事项

### 数据安全
- 初始化脚本会检查现有数据，避免重复创建
- 如果数据已存在，会跳过创建并显示提示信息
- 不会删除或覆盖现有数据

### 生产环境
- 生产环境建议修改默认管理员密码
- 建议关闭 TypeORM 的 `synchronize` 选项
- 使用环境变量管理敏感配置

### 故障排除

**连接数据库失败**
- 检查MySQL服务是否运行
- 验证数据库连接配置
- 确保数据库已创建

**权限错误**
- 确保数据库用户有足够权限
- 检查防火墙设置

**TypeScript编译错误**
- 运行 `npm install` 确保依赖完整
- 检查 TypeScript 配置

## 🔄 重新初始化

如果需要重新初始化数据库：

1. **清空数据库**（谨慎操作）
2. **重新运行初始化脚本**
```bash
npm run init-db
```

## 📞 技术支持

如果在初始化过程中遇到问题：

1. 检查控制台输出的错误信息
2. 查看数据库连接状态
3. 确认所有依赖已正确安装
4. 参考 `MYSQL_SETUP.md` 进行数据库配置

---

**提示**: 首次部署建议先运行 `npm run init-db` 创建完整的初始数据，后续可以根据需要使用其他初始化命令。
